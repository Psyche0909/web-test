# 徐州红色工业遗产网站

这是一个展示徐州红色工业遗产的网站项目，旨在宣传和保护徐州地区珍贵的工业遗产，传承红色精神和工业文明。

## 项目简介

本项目是基于Vue.js开发的网站，主要展示徐州地区的红色工业遗产，包括煤矿、铁路、纺织等不同类型的遗产资源。网站设计风格以故宫红为主色调，搭配工业灰和鎏金色，体现中国传统与工业文明的结合。

## 主要功能

- **首页**: 展示网站整体信息和精选工业遗产
- **项目介绍**: 介绍徐州红色工业遗产保护项目
- **工业遗产**: 展示不同类型的工业遗产，点击可查看详情页面
  - 煤矿遗产
  - 铁路遗产
  - 纺织遗产
  - 其他工业遗址
- **红色精神**: 介绍徐州工业发展过程中形成的红色精神
- **答题游戏**: 工业文化知识问答游戏
- **全景地图**: 工业遗址VR全景展示
- **文创产品**: 基于工业遗产开发的文创产品展示

## 技术栈

- Vue.js 3
- Vite
- HTML/CSS/JavaScript

## 设计特点

- **配色方案**: 故宫红(#8B1A1A)、工业灰(#666)、鎏金色(#D4AF37)、米黄底色(#F8F4E9)
- **布局设计**: 参考故宫博物院网站布局，结合工业主题特色
- **交互体验**: 流畅的动画效果和响应式设计，适配不同设备
- **文化传承**: 通过现代设计手法展现传统工业文化

## 本地开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 页面预览

- **首页**: 展示网站主要内容和精选工业遗产
- **工业遗产页面**: 详细介绍不同类型的工业遗产，包括历史、特色和保护状况
- **答题游戏**: 通过答题了解徐州工业文化
- **全景地图**: 360°体验工业遗址风貌

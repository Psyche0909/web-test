# 整体布局设计

## 一、顶部导航栏（固定在顶部）
- **左侧**：Logo（如徐州红色工业遗产文字+工业元素图标）  
- **右侧**：导航菜单（水平排列）：  
  `首页 | 项目介绍 | 工业遗产 | 红色精神 | 答题游戏 | 全景地图 | 文创`  
  - **下拉菜单设计（工业遗产）**：  
    下拉框内容：`煤矿遗产 | 铁路遗产 | 纺织厂遗产 | 其他工业遗址`  
  - **下拉菜单设计（红色精神）**：  
    下拉框内容：`煤矿精神 | 铁路精神 | 劳模精神 | 其他工业精神`  
  - **交互效果**：缓慢向下展开动画，背景采用毛玻璃效果  

> **答题游戏**：做成"工业知识闯关"形式，用齿轮、火车头等作为进度标识（点击选项跳转至对应子页面）。

---

## 二、主视觉区（首页顶部）
- **大型轮播图**：展示徐州标志性红色工业遗产（如徐州煤矿纪念馆、贾汪铁路旧址等），配简洁标题文字。  
- **工业风格元素**：在轮播图底部加入传统纹样边框或暗红色渐变分隔线。  

---

## 三、内容展示区（首页主体）
1. **第一板块**：简介文字（徐州红色工业遗产的历史意义+红色精神传承）。  
2. **第二板块**：精选遗产展示（用卡片式布局，图片+名称，点击跳转详情）。  
3. **第三板块**：动态模块（如“今日推荐遗产”或“答题游戏入口”）。  
4. **底部**：版权信息、合作单位logo等。  

---

## 四、配色方案
- **主色**：故宫红 `#8B1A1A`  
- **辅色**：工业灰 `#666`、鎏金 `#D4AF37`  
- **背景色**：米黄色 `#F8F4E9`

# 新增聊天机器人系统 - 前端设计说明

## 1. 首页导航栏添加“AI智能体”导航项

- 修改顶部导航栏组件（例如：`Navbar.vue`）
- 在导航栏左侧“工业文化”旁添加一个新的导航项：“AI智能体”
- 点击“AI智能体”后跳转至对应页面（详见第 2 步）

## 2. 新增“AI智能体”页面（效果类似图2）

- 新建页面组件：`AiAgent.vue`
- 页面内容包含：
  - 卡通形象展示（参考图2）
  - 一个“开始对话”按钮
  - 底部功能栏，包含两个选项：
    - **全景地图**（点击后跳转至已实现的全景地图页面）
    - **工业文化**（点击后跳转至已实现的工业文化页面）

## 3. 对话弹窗或页面跳转

- 点击 AI 卡通形象或“开始对话”按钮，进入聊天对话界面
- 聊天界面内容包括：
  - 聊天历史消息展示
  - 输入框，用于输入问题
